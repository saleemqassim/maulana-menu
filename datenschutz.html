3. Welche Daten werden erhoben?

3.1 Server-Logfiles (Vercel)

Unsere Website wird über den Hosting-Dienst Vercel Inc. (340 Pine Street, Suite 701, San Francisco, CA 94104, USA) bereitgestellt. Bei jedem Aufruf der Website speichert Vercel automatisch folgende Daten in sogenannten Server-Logfiles:

  • IP-Adresse des anfragenden Geräts (gekürzt)
  • Datum und Uhrzeit des Zugriffs
  • Name der abgerufenen Datei
  • Übertragene Datenmenge
  • Browsertyp und Betriebssystem
  • Referrer-URL (zuvor besuchte Seite)

Diese Daten werden ausschließlich zur technischen Bereitstellung der Website und zur Erkennung von Angriffen verwendet. Die Speicherung erfolgt für max. 30 Tage. Rechtsgrundlage: Art. 6 Abs. 1 lit. f DSGVO (berechtigtes Interesse an der sicheren Bereitstellung des Dienstes).

Vercel ist nach dem EU-US Data Privacy Framework zertifiziert. Datenschutzinformationen: vercel.com/legal/privacy-policy

3.2 Vercel Web Analytics

Wir nutzen Vercel Web Analytics zur Analyse der Websitenutzung. Dieses System verwendet keine Cookies und speichert keine personenbezogenen Daten. Es werden nur aggregierte, anonymisierte Kennzahlen erhoben (Seitenaufrufe, Verweildauer, verwendete Gerätetypen). Eine Rückverfolgung auf einzelne Personen ist nicht möglich.

Da keine personenbezogenen Daten verarbeitet werden, ist für diese Funktion keine Einwilligung erforderlich. Rechtsgrundlage: Art. 6 Abs. 1 lit. f DSGVO.

3.3 Schriftarten (selbst gehostet)

Diese Website verwendet die Schriftarten Cormorant Garamond und Lato. Die Schriftartdateien werden direkt von unserem Server ausgeliefert — es findet keine Verbindung zu Google-Servern oder anderen externen Diensten statt. Es werden dabei keine personenbezogenen Daten übermittelt.

3.4 Externe Links

Unsere Website enthält Links zu folgenden externen Diensten:

  • Google Maps: Beim Klick auf den Kartenlink werden Sie zu Google Maps weitergeleitet. Ab diesem Zeitpunkt gelten die Datenschutzbestimmungen von Google LLC. Wir betten keine Google Maps-Karte ein.
  • WhatsApp: Der WhatsApp-Link öffnet die WhatsApp-App auf Ihrem Gerät. Es werden keine Daten übermittelt, bevor Sie selbst auf den Link klicken.
  • Instagram / TikTok: Die Social-Media-Links leiten Sie zu den jeweiligen Plattformen weiter. Es findet keine Einbettung von Social-Media-Elementen auf unserer Website statt.
